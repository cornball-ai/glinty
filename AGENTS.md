# glinty project instructions

- Use glinty's component and token vocabulary so interfaces work across its
  supported frontends. Treat raw HTML, arbitrary tags, and custom CSS as possible
  gaps in reusable components.
- When a gap blocks requested work, explain the generic framework gap and
  propose the reusable component. Get approval before posting upstream and
  keep private consumer details out of public issues.
- An authorized temporary app override needs a clear replacement path.
  Do not turn a one-off workaround into a requirement for unrelated apps.
